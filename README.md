# Garten- und Landschaftspflege Streich

Website: [www.garten-streich.de](https://www.garten-streich.de)

## Stack
- React (CRA/CRACO) in `frontend/`
- Hosting: Cloudflare Pages
- CMS: Decap (Passwort-Login, Git Gateway)

## Lokal starten
```bash
cd frontend
yarn install
yarn start
```

## Build
```bash
cd frontend
yarn build
```

Deploy- und Env-Hinweise: `frontend/CLOUDFLARE.md`  
CMS: `frontend/CMS.md`
